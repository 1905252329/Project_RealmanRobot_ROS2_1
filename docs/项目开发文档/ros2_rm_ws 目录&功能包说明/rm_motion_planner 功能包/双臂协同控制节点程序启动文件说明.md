## 双臂协同控制节点程序启动文件说明

双臂驱动节点的启动文件功能：

- 包含左臂和右臂驱动节点
- 使用命名空间隔离（left_arm 和 right_arm）
- 分别使用独立的配置文件（rm_left_arm_config.yaml 和 rm_right_arm_config.yaml）
- 

### 源码

`rm_driver/launch/rm_dual_arm_driver.launch.py`

```python
import launch
import os
import yaml
import launch_ros
from launch import LaunchDescription
from launch_ros.actions import Node
from launch.substitutions import Command, LaunchConfiguration
from ament_index_python.packages import get_package_share_directory
from launch.actions import GroupAction
from launch_ros.actions import PushRosNamespace


def generate_launch_description():
    # 左臂配置文件
    left_arm_config = os.path.join(get_package_share_directory('rm_driver'),'config','rm_left_arm_config.yaml')
    
    # 右臂配置文件
    right_arm_config = os.path.join(get_package_share_directory('rm_driver'),'config','rm_right_arm_config.yaml')

    # 左臂驱动节点组
    left_arm_group = GroupAction([
        PushRosNamespace('left_arm'),
        Node(
            package="rm_driver",
            executable="rm_driver",
            name="left_arm_driver",
            parameters=[left_arm_config],
            output='screen',
        )
    ])
    
    # 右臂驱动节点组
    right_arm_group = GroupAction([
        PushRosNamespace('right_arm'),
        Node(
            package="rm_driver",
            executable="rm_driver",
            name="right_arm_driver",
            parameters=[right_arm_config],
            output='screen',
        )
    ])

    return LaunchDescription([
        left_arm_group,
        right_arm_group
    ])
```

## 完整的双臂系统启动文件说明

已经有了规划器节点的启动文件，但还需要一个能够启动驱动节点和规划器节点的完整启动文件。

通过以下命令启动完整的双臂系统：

```bash
ros2 launch rm_bringup rm_dual_arm_bringup.launch.py
```

这个启动文件会同时启动：

- 左臂驱动节点（在 left_arm 命名空间下）
- 右臂驱动节点（在 right_arm 命名空间下）
- 双臂规划器节

### 源码

###### 注释代码的含义

```python
# launch_arguments={
#     'arm_ip': '192.168.1.18'
# }.items()
```

这段代码是用来向被包含的启动文件（included launch file）传递参数的。具体来说：

- **`launch_arguments`**：这是 `IncludeLaunchDescription` 的一个参数，用于向被包含的启动文件传递参数
- **`{'arm_ip': '192.168.1.18'}.items()`**：创建一个字典并调用 `items()` 方法，将键值对作为参数传递
- **作用**：如果取消注释，会将 `arm_ip` 参数传递给 [rm_75_driver.launch.py](javascript:void(0)) 启动文件



为什么要注释掉？

1. **参数传递方式**

当前实现通过配置文件而不是启动参数来设置机械臂的IP地址：

- 左臂IP地址在 [rm_left_arm_config.yaml](javascript:void(0)) 中设置为 `192.168.1.18`
- 右臂IP地址在 [rm_right_arm_config.yaml](javascript:void(0)) 中设置为 `192.168.1.19`

2. **设计考虑**

注释掉的原因包括：

- **配置集中管理**：将IP地址等配置参数集中在YAML配置文件中，便于维护和修改
- **避免参数冲突**：如果同时使用launch参数和YAML配置，launch参数会覆盖YAML配置（根据ROS 2参数加载优先级规则）
- **保持灵活性**：通过配置文件方式可以更灵活地管理不同机械臂的参数

3. **两种方式对比**:

​	1)方式一：通过launch参数传递

```python
launch_arguments={
    'arm_ip': '192.168.1.18'
}.items()
```

- 优点：参数传递明确，便于在启动时动态修改
- 缺点：参数分散在多个地方，不易维护

​	2)方式二：通过配置文件管理（当前采用）

```python
# 使用rm_driver/config中的配置文件
```

- 优点：配置集中，便于维护，符合ROS 2参数管理最佳实践
- 缺点：修改配置后可能需要重新编译（在某些情况下）



**结论**

注释掉这段代码是为了采用更规范的参数管理方式，即通过YAML配置文件而不是launch参数来设置机械臂的IP地址等参数。这种方式更符合ROS 2的最佳实践，便于维护和管理

left_arm_driver = IncludeLaunchDescription(
    PythonLaunchDescriptionSource(
        os.path.join(get_package_share_directory('rm_driver'), 'launch', 'rm_dual_arm_driver.launch.py')
    )
)
## 右臂驱动

###### 功能说明

这段代码的意思是：

1. 通过`IncludeLaunchDescription`包含其他launch文件

2. `PythonLaunchDescriptionSource`指定要包含的launch文件路径

3. 这里是要包含我们之前创建的双臂驱动启动文件，用于启动左右臂的驱动节点

   

使用了命名空间（namespace）来隔离左右臂的话题和服务，这样可以确保：

- 左臂话题：`/left_arm/movej_canfd_cmd`、`/left_arm/joint_states`等
- 右臂话题：`/right_arm/movej_canfd_cmd`、`/right_arm/joint_states`等

这与我们在双臂规划器节点中实现的话题发布和订阅是一致的。

这样的设计使系统更加清晰和模块化，您可以根据需要选择启动方式
